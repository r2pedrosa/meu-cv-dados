# Currículo Técnico - Data Engineering

Este repositório contém o código-fonte do meu currículo profissional desenvolvido em **LaTeX**.

## 🎯 Objetivo do Repositório
Documentar a evolução do meu perfil profissional e servir como um exemplo prático de versionamento de documentos técnicos utilizando **Git**.

## 🛠️ Tecnologias Utilizadas
* **LaTeX** : Estruturação e design do documento para garantir rigor visual.
* **Git**   : Controle de versão e gestão de branches (ex: `feature/versao-ingles`).
* **GitHub**: Cloud storage e portfólio público.

## 📄 Estrutura do Projeto
* `main.tex`: Versão principal do currículo em Português.
* `resume.tex`: Versão em Inglês (focada em oportunidades globais).
* `main.pdf`: Documento final compilado.
